# David: The Shepherd's Sling

A side-scrolling platformer that follows young David from the sheep fields of Bethlehem to the Valley of Elah, told
with Pixar-style characters and classic NES-style controls. 8 worlds, 32 stages, 8 bosses. Plays in a web browser on a
computer or TV, with a keyboard or a game controller.

## Controls

| Controller | Keyboard | Action |
|---|---|---|
| D-pad | Arrow keys | Move (hold to run) · Up / diagonal to aim |
| A | Z or Space | Jump |
| B | X | Sling (tap) · hold to charge |
| Down + A | Down + Z | Roll |
| Select | Shift | Play the harp |
| Start | Enter | Pause / the Shepherd's Journal |

H shows or hides the controls. Click the game once to turn on sound (browsers need a click before they play audio).
To use a controller, press a button on it so the browser sees it; M sets one up.
